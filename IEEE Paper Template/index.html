I. Introduction

Urban sensing platforms increasingly combine low-power devices, edge processors, and learning-based decision systems. Their value depends on a difficult balance: inference should remain accurate while communication and computation stay within tight energy budgets. Centralized approaches can provide strong models, but they introduce latency, network dependence, and privacy concerns [1].

This paper studies an adaptive controller that selects sensing rates and model complexity from observed workload conditions. The main contributions are threefold: (1) a lightweight formulation for joint energy and accuracy control; (2) an edge-first architecture that limits unnecessary transmission; and (3) an evaluation protocol that reports both predictive and system-level outcomes.

The remainder of the paper is organized as follows. Section II summarizes related work. Section III defines the system model, Section IV presents the method, and Section V discusses the results.

II. Related Work

Prior research spans adaptive sampling, mobile inference, and resource-aware learning. Dynamic sampling reduces redundant observations by reacting to signal variation [2], while split-computing methods distribute inference across device, edge, and cloud tiers [3]. These lines of work motivate a controller that treats sensing and inference as one decision rather than independent optimization stages.

A. Adaptive Sensing

Adaptive policies commonly use thresholds, uncertainty scores, or learned state models. Threshold methods are inexpensive but can be brittle under distribution shift. Learned policies are more flexible, although their own execution cost should be included in the energy model.

B. Edge Intelligence

Edge execution can improve response time and data locality. The resulting design space includes model size, quantization level, batch size, and radio use. A practical study should disclose the hardware, measurement interval, and baseline configuration so the reported gains remain reproducible.

III. System Model

Consider a set of sensor nodes i ∈ {1, …, N} connected to a nearby edge gateway. At decision step t, each node selects a sampling rate si,t and an inference profile mi,t. The objective minimizes normalized energy while penalizing predictions below a target accuracy.

J = min ∑t=1T [ Et + λ max(0, A* − At) ] (1)

Here, Et is total energy, At is observed task accuracy, A* is the required accuracy, and λ controls the penalty. Define all symbols immediately before or after each equation, and number only equations referenced later.

IV. Proposed Method

The controller receives a state vector containing signal variance, queue occupancy, recent inference confidence, and battery state. It then chooses an action from a small set of validated sensing–model pairs. Restricting the action set reduces decision overhead and prevents unsafe configurations.

A. Controller Design

At initialization, each device profiles candidate actions on a calibration trace. Runtime scores combine predicted energy and an accuracy-risk term. A short hysteresis window prevents rapid oscillation between adjacent profiles.

Algorithm 1 Adaptive profile selection
  1. Observe state xt and available energy bt.
  2. Estimate cost J(a | xt) for each feasible action a.
  3. Reject actions that violate the accuracy floor or battery constraint.
  4. Select the lowest-cost action and apply the hysteresis rule.
  5. Update the rolling statistics using the observed outcome.

B. Complexity

For K candidate profiles, selection requires O(K) score evaluations and O(1) state updates. The controller stores only rolling statistics, so memory use does not grow with deployment time.
